# TriFold Project Page

Project page for **TriFold: Folding Irregular 3D Gaussians into Structured Latents for 3D Scene Generation** (ICLR 2027 submission, under review).

Website template adapted from [Fantasy-AMAP/fantasy-world](https://github.com/Fantasy-AMAP/fantasy-world) (`page` branch), originally based on the [Nerfies](https://github.com/nerfies/nerfies.github.io) project page.
